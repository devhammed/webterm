# PHP Web Terminal

This is a proof-of-concept Web Terminal written in PHP.

## Technologies

- PHP 8.4+
- Composer 2+
- Ratchet PHP
- Websocket
- Xterm.js

## Usage

```shell
git clone git@github.com:devhammed/webterm.git

composer install

php bin/server.php
```

Then, you can access the terminal at `http://localhost:8080`.
